# Test case 1: Constant sliding

Thesis section: 5.4.3.1.

A prism split by an inclined frictional interface is loaded by a prescribed vertical displacement. Plane-strain constraints allow comparison with the two-dimensional analytical solution, whose tangential gap is uniform. The mortar contact solution is checked against the exact sliding magnitude and contact state.

Run `main` after `initGReS`. Case-specific inputs and helpers are in `Input/` and `Utils/`. Results are written to `Output/`, whose previous contents are replaced on each run.
