# Test case 2: Sneddon’s problem

Thesis section: 5.5.4.2.

An internal fracture is pressurized in an elastic plane-strain domain. Analytical displacement boundary conditions reduce far-field boundary effects. The computed normal gap is compared with Sneddon's opening profile, and successive structured-mesh refinements are used to measure the relative L2 opening error.

Run `main` after `initGReS`. Case-specific inputs and helpers are in `Input/` and `Utils/`. Results are written to `Output/`, whose previous contents are replaced on each run.
