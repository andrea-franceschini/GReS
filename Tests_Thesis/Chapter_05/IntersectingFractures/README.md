# Test case 3: Multiple intersecting fractures

Thesis section: 5.5.4.3.

Six embedded fractures form an intersecting network in a loaded elastic domain. The test examines kinematic interactions using superposed fracture enrichments and qualitatively compares displacement and stress patterns with the reference discrete-fracture benchmark. Stress release along sliding segments and concentrations near fracture tips are of particular interest.

Run `main` after `initGReS`. Case-specific inputs and helpers are in `Input/` and `Utils/`. Results are written to `Output/`, whose previous contents are replaced on each run.
