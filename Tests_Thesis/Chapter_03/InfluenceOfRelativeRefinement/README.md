# Influence of the relative refinement

Thesis section: 3.3.1.

Uses the two-subdomain manufactured Poisson problem to compare coarse and fine choices of the multiplier side. Interface multiplier profiles reveal oscillations associated with excessive constraints; standard, dual, and stabilized P0 formulations are compared against the exact interface flux.

Run `main` after `initGReS`. Case-specific inputs and helpers are in `Input/` and `Utils/`. Results are written to `Output/`, whose previous contents are replaced on each run.
